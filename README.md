# Student Record Management System

A console-based Student Record Management System built using C.

## Features

- Add student records
- Display all student records
- Search student by roll number
- Update student details
- Delete student records
- Menu-driven interface

## Concepts Used

- Structures (`struct`)
- Arrays
- Functions
- Pointers
- Strings
- Loops and conditional statements
- Linear search

## How to Run

### Compile

```bash
gcc student.c -o student
```

### Run

```bash
.\student.exe
```

## Menu

```text
===== Student Record Management System =====

1. Add Student
2. Display Students
3. Search Student
4. Update Student
5. Delete Student
6. Exit
```
